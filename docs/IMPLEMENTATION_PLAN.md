# たま勉強RPG 精密実装計画書

## 目的

生成済みUI画像の雰囲気、配色、余白、角丸、紙質、アイコン表現をできるだけ忠実に再現しながら、iPad Safari と GitHub Pages で動く React 製の「勉強RPG + 箱庭ゲーム」を実装する。

静止画そのものを表示するだけではなく、クエスト完了、JSONインポート、ガチャ、町づくり、図鑑、ショップ、設定、簡易マイルーム編集が操作できるゲームとして構築する。

## 再現方針

- 生成済み画像を一次リファレンスとして `public/assets/generated/` に保存する。
- UIは `ui-home-reference.png` の構図を基準にする。
- 実装に使う背景、主人公、リーフェル、町、家具、ガチャ、精霊、クエスト、素材はシート画像から切り出して `public/assets/crops/` に配置する。
- アイコンやキャラクター切り出し画像は透過PNGにする。
- フォントは日本語環境で自然に表示される `Yu Gothic`, `Hiragino Sans`, `Noto Sans JP` 系を使い、画像の丸くやさしいUIに寄せる。
- パネルはクリーム色、紙テクスチャ風、細いベージュ線、淡い影、8-24pxの角丸を基本にする。
- アニメーションは控えめに、癒し系ゲームらしく入れる。

## 機能実装

- ホーム
  - 主人公中央表示、リーフェル隣表示、会話バブル。
  - 今日のクエスト、リカバリークエスト、今週の予定、学習時間、ワーク進捗、町の発展度、図鑑導線。
  - XP、コイン、ダイヤ、Lvを常時表示。
- クエスト
  - メイン、サブ、リカバリーの切り替え。
  - 完了ボタンでXP/コイン/素材を付与。
- 記録/JSONインポート
  - ChatGPT Projectが出力した1日分JSONを貼り付け、XP/Coin/completedQuests/recoveryQuests/studyMinutesを反映。
- ガチャ
  - 「ごほうびクローゼット」。
  - 1回/10回ガチャ、N/R/SRの衣装・髪型・アクセサリーを排出。
  - 精霊は絶対に排出しない。
- 町づくり
  - 町Lvと成長度を表示。
  - 花/本/灯り/くつろぎなどのテーマ値により精霊が自然来訪。
- 図鑑
  - 精霊、家具、衣装、素材カテゴリ。
- ショップ
  - 家具購入、コイン消費、インベントリ追加。
- 設定
  - テスト名、テスト日、ワーク総ページ、完了ページを保存。
- マイルーム
  - 家具の配置、回転、削除、保存ができる簡易グリッド。

## アニメーション基準

- 主人公: ゆっくり上下に浮くような breathing。
- リーフェル: 小さくふわふわ漂う。
- パネル: 表示時に軽い fade/slide。
- ガチャ: 実行時に光の粒とカード出現。
- 報酬: XP/コイン加算時に小さな sparkle。
- 町: 成長度に応じて柔らかな glow。
- `prefers-reduced-motion` ではアニメーションを抑える。

## 品質基準

- 1448x1086基準の生成UIに近い構図。
- iPad横向きでファーストビューに主要UIが収まる。
- 1024px幅以下ではカードが縦積みになり、テキストが重ならない。
- localStorage保存がリロード後も復元される。
- 画像アイコンは透過処理済みPNGを使用する。
- Browser Useで見た目と操作を確認する。
